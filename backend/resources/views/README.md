# Views Relocated to Root `frontend/views/`

To maintain a clean two-folder root separation (`frontend/` and `backend/`) within Laravel 10 MVC:

- **All Blade Templates (`.blade.php`)**: Located in [`../../frontend/views/`](../../frontend/views/) (configured automatically in [`backend/config/view.php`](../../config/view.php)).
- **Client-Side JavaScript**: Located in [`../../frontend/js/`](../../frontend/js/).
- **Styles & Images**: Located in [`../../frontend/src/styles/`](../../frontend/src/styles/) and [`../../frontend/public/images/`](../../frontend/public/images/).
