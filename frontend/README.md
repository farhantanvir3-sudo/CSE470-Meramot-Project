# Meramot Frontend — Views & Asset Pipeline

Frontend styling, interface templates, and reactive component layer for the Meramot electronic repair marketplace.

In accordance with BRAC University CSE 470 guidelines:
- **Styling**: Tailwind CSS with custom branding design tokens
- **Reactivity**: Alpine.js for lightweight, performant client interactions
- **Icons**: Lucide Icons
- **Integration**: Compiles assets for both standalone preview and Laravel Blade MVC view templates.

## Scripts

```bash
# 1. Install dependencies
npm install

# 2. Watch Tailwind CSS changes during development
npm run watch:css

# 3. Production CSS Minification
npm run build:css
```
